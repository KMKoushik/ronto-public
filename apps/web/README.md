# Ronto Web

The authenticated React client for Ronto. It uses Vite, React 19 with React Compiler, TanStack Router, TanStack Query, Tailwind CSS, and the shared contracts in `packages/api`.

Run it from the repository root with `pnpm dev`. Vite listens on `http://localhost:2718` and proxies `/api` to the server on `http://localhost:3141`.

Architecture and product status are documented in [`../../docs/architecture.md`](../../docs/architecture.md) and [`../../docs/roadmap.md`](../../docs/roadmap.md).
